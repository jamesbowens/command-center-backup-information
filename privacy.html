Privacy policy

Command Center Private Backups · Updated November 3, 2026

This personal utility is operated by James Owens for his own backup and recovery needs. It does not accept public user registrations.

Google data and permissions

The utility requests Google's drive.file permission. It can create and manage its own backup files and access files specifically authorized for it. It uses file identifiers, names, sizes and related metadata to upload encrypted recovery archives, locate them and verify downloads. It does not request access to all Drive files, Gmail, contacts or calendars.

Use, storage and transfer

Authorized backup jobs run in the owner's private GitHub repository. The runner temporarily processes recovery data, encrypts it, and transfers encrypted archives to the owner's Google Drive. The backup decryption key is not given to the cloud runner. Google authorization credentials are stored in GitHub Actions' protected secret store and in protected local setup storage. Google and GitHub process data under their respective service policies.

Google user data is used only to operate, verify and recover backups. It is not sold, used for advertising, or used to train AI models. Archive contents are not published. Routine job output is limited to operational status, counts and checksums; credentials and record contents are excluded.

Retention and control

Backups remain in the owner's Drive until the owner deletes them. There is no automatic purge in the current setup. The owner can stop scheduled jobs and revoke the utility's access in Google Account permissions. Revocation stops future access and does not delete existing backup files. Local setup files and stored GitHub credentials must be removed separately when retiring the utility.

For questions about this personal utility, contact the operator through the James Owens GitHub profile.
